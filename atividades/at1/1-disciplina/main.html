INF 321 - Projeto e Desenvolvimento de Sistemas Web

Professor

Dr. João da Silva

Descrição

Essa disciplina tem como objetivo ensinar os fundamentos do
desenvolvimento web, incluindo HTML, CSS e JavaScript. Os
alunos aprenderão a criar páginas web interativas e responsivas,
além de compreender as melhores práticas de design e usabilidade.

Conteúdo

O conteúdo da disciplina abrange desde a introdução ao desenvolvimento web,
passando pela estruturação de páginas com HTML, estilização com CSS,
programação com JavaScript, até o uso de frameworks e bibliotecas, em especial a linguagem Elixir e o framework Phoenix.
Os alunos também serão incentivados a seguir boas práticas de desenvolvimento
e a criar projetos práticos ao longo do curso.
